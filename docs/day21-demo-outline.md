## 第 1 段｜用户问题：他要解决什么（约 40 秒）

**说**：想给品牌、店铺、宠物、网络昵称起名的人，平时靠拍脑袋和翻字典——费时，而且越想起不出。他要的不是"AI 很酷"，是**输入一个想法，10 秒内拿到一批带解释的名字，打开就能用，不用注册**。

**点**：打开公网首页 → 停在首屏。
- 屏幕上只有三样东西：一句话说明、表单、生成按钮——**没有任何登录/注册入口**（彩排实测：页面里不存在密码框等账号控件）。
- 一句话概括北极星：**不注册、不学习，30 秒内拿到第一次结果。**

## 第 2 段｜核心流程：从想名字到拿到结果（约 45 秒）

**说**：只有一条主线，四步。**选场景 → 写关键词 → 点生成 → 复制走**。

**点**（照着走）：
1. 「用在哪儿」选**店铺**（默认是「品牌」）；
2. 关键词写「**海边咖啡店，安静治愈**」（会提示 1–20 个字）；
3. 点「✨ 生成名字」——**先出现 6 块骨架屏**（加载状态），结果到了再换成真卡片；
4. 结果区出现 **6 张卡片**：名字 + ≤30 字寓意 + 「复制」按钮；点一下「复制」，按钮变绿、弹出「已复制「半山书角」到剪贴板」；
5. 顺手展示两个细节：结果上方的**按字数筛选**（全部 / 2 字 / 3 字 / 4 字，筛空会给出「看全部」出口）；底部**每日免费 5 次**的额度提示——**成功才扣，失败不扣**。

**彩排实测的数字（可以直接念）**：点完到出现结果 **1.00 秒**（标准是 ≤10 秒）；卡 6 张；额度从「还能 5 次」变成「还能 4 次」；复制 toast 正常。
**诚实说明**：这一步用的是**本地示例数据 + 规则组合**（`MOCK_MODE = true`），真模型接口 `/api/generate` 合同已签、实现排在第 4 周——演示时主动说出来，别让人以为这是真模型。

## 第 3 段｜提示词改写：把"别人的示例"翻成"自己的需求"（约 45 秒）

**说**：这一周真正练的手艺是这句——**课程清单给的是通用示例（热搜、收藏），我的项目不需要那些；我把示例里的"名词"换成 peach 的真实结构，但一条验收标准都不降低。**

**点**：翻到首页下方「**名字库实时数据**」区，指着实时数字说这是**数据库此刻的样子**（6 个场景 / 37 个名字 + 场景分布 + 真名卡片）。

| 清单里的示例（别人的项目） | 改写后（peach 的真实需求） | 改写原则 |
| --- | --- | --- |
| `GET /api/hot`（热搜榜） | `GET /api/scenes`（场景字典） | 换数据对象，不换形状：仍是"一个 GET，回一批列表" |
| `GET /api/favorites`（收藏列表） | `GET /api/library?scene=&keyword=&limit=`（词库查询） | 换业务含义，保留分页/筛选这类通用能力 |
| `POST` 收藏写入 | `POST /api/names`（投稿收录一个名字） | 换名词，**防重复 / 错误输入这两条标准原样照做**（409 / 400 中文人话） |
| 「检查台 + 最后更新时间」 | 首页「名字库实时数据」区 + 检查台三行 | 换挂载位置，保留"用户能自己确认系统活着"这件事 |

**一句话收口**：**需求可以改名词，标准不能打折**——这才是"翻译"，不是"缩水"。

## 第 4 段｜验证方式：凭什么说它真的能用（约 45 秒）

**说**：我不说"我测过了"，我给出四类可核对的证据。

**点 / 展示**：

| 验证方式 | 现场展示 | 对应证据 |
| --- | --- | --- |
| ① 公网自测 | 地址栏就是公网域名，直接发给别人也能打开 | `docs/day21-peer-check.md` ① 可打开 |
| ② **改库跟着变** | 在数据库里改一行寓意 → 刷新页面 → 页面文字跟着变 | `docs/day20-verify.md` 第 5 节 + 截图 `day20-home-updated-bar.png` |
| ③ **独立通道交叉验证** | 换一套判据、只走公网、从头写脚本再点一遍 | 三行结论：**可打开 ✅ / 可读写 ✅ / 无报错 ✅** |
| ④ 全接口回归 | 接口路径、字段、状态码一个没变 | `docs/day19-verify.md`（本地 23 项 + 公网 22 项） |

**补一句最关键的**：**能自己验证，才算"能用"**——所以我在页面上专门做了检查台三行（🛰 云函数自检 / 🕘 数据最后更新=服务端时间 / ⚡ 本次读取），任何人打开页面就能确认"这不是一张写死的截图"。
