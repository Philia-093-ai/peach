## v1.0 里有什么

- **生成器**：写关键词 → 拿一批带寓意的中文名字；按字数筛选；复制带动静双通道反馈
- **词库**：按场景翻真库（PostgreSQL），支持搜索、四种状态（加载/空/成功/错误）、删除两步确认
- **关于**：三个视图的说明、免费额度、数据来源、版本号
- **实时数据区**：首页显示的名字库统计与预览来自云数据库，不是写死的
- **接口**：`GET /api/health`、`GET /api/scenes`、`GET /api/library`、`POST /api/names`、`PATCH /api/names/:id`、`DELETE /api/names/:id`、`POST /api/names/:id/restore`
- **错误一律说人话**：三类错误（请求有问题 / 找不到 / 服务异常）都有中文提示，不暴露状态码和堆栈

## 两个「版本号」不是一回事（容易搞混，特意说清）

| 版本号 | 在哪 | 现在是多少 | 什么时候动 |
| --- | --- | --- | --- |
| **产品版本** | 页脚徽标 `peach v1.0` + git tag `v1.0` | v1.0 | 整体发布节点 |
| **接口版本** | `/api/health` 返回的 `version` + `cloudfunctions/api/package.json` | 1.5.0 | 每次接口有变更 |

所以看到「接口 1.5.0」和「产品 v1.0」并存不是矛盾：接口改了 5 次，产品才发第 1 个正式版。
