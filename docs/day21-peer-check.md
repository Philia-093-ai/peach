## 3. 验证完的数据收尾

写路径是真写（这是判据「可读写」的核心），所以验完必须收尾：

| 步骤 | 结果 |
| --- | --- |
| 写前 | `names` = 37 行（seed 36 + Day 18 投稿「云栖」1） |
| 写入「晴窗」 | 201，id=88 → 品牌场景 count 7→8，全库 38 |
| 读回 | `/api/library?scene=品牌` 含「晴窗」→ 写路径端到端成立 |
| 清理 | `DELETE FROM names WHERE name = '晴窗'` → **Affected rows: 1** |
| 清理后 | `SELECT count(*) FROM names` → **37**（回到验收前） |

> 这里的 `DELETE` 是**清理调试数据的 SQL**，不是接口——项目里没有 DELETE 接口（那是第 4 周的事）。
