## 3. 验收官检测发现的问题（1 个，已修复）

| 项 | 内容 |
| --- | --- |
| 现象 | 首页「名字库实时数据」检查台显示「6 个场景 · **7** 次请求」，实际发了 **8** 个请求（1 次 `/health` + 1 次 `/scenes` + 6 次按场景 `/library`） |
| 根因 | `public/live.js` 的 `liveMetaBlock` 写死了 `sceneCount + 1`，漏算了 `/scenes` 那一次 |
| 性质 | 显示数字与事实不符——检查台是给用户看的「自检台」，数字错比没有更糟 |
| 修复 | `sceneCount + 1` → `sceneCount + 2`（`public/live.js`，1 行），并同步修正 `public/mock.js` 里同一处过时注释 |
| 验证 | 重新部署（9 文件校验通过）→ 线上 `live.js` 已含修复 → 在最终构建上把 15 项前端验收**完整重跑一遍**，仍 15/15 |
